# SWOS Scout

App Android per cercare e filtrare i giocatori di Sensible World of Soccer a partire da un file CSV.

- Dati integrati in `app/src/main/assets/players.csv`; dal menu si può caricare un CSV diverso (separatore virgola o punto e virgola).
- Menu: la mia squadra, confronto giocatori, carica CSV, lingua (IT/EN/FR/DE), tema chiaro/scuro.
- Preferiti e valori modificati restano salvati sul telefono.
- Build: GitHub Actions (`.github/workflows/build.yml`) produce l'APK debug come artifact.
